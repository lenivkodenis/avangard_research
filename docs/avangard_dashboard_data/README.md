# Avangard dashboard data package

## Состав

- clean_deals.csv — очищенная полная таблица по уникальным VIN.
- risk_deals.csv — сделки высокого и критического риска.
- dealer_summary.csv — сводка по автосалонам.
- employee_summary.csv — сводка по сотрудникам.
- risk_combinations.csv — ключевые риск-сценарии.
- ocp_gap_top50.csv — топ-50 минусов к МЦП.
- data_quality.csv — контроль качества данных.
- state_summary.csv — сводка по состоянию.
- price_segment_summary.csv — сводка по ценовым сегментам.
- sales_below_ocp.csv — автомобили из нового отчёта Auto.ru, реализованные ниже МЦП.
- resold_deals.csv — автомобили, найденные снова в продаже после Авангарда.
- resold_summary.csv — KPI исследования «Перепродано».
- resold_by_seller_type.csv — сводка перепродажи по типу продавца.
- resold_by_region.csv — сводка перепродажи по регионам.
- resold_by_risk_level.csv — сводка перепродажи по уровню риска основной модели.
- resold_by_employee.csv — сводка перепродажи по оценщику.
- resold_top_gap.csv — найденные перепродажи, отсортированные по максимальной разнице цен.
- codex_prompt_html_dashboard.md — готовый обновлённый промпт для Codex.

## Методология

- Период считается уже отфильтрованным в исходных файлах.
- VIN-дубли схлопнуты.
- Состояние D включено в основную выборку по текущей версии витрины.
- Битый оставлен отдельной категорией.
- Пустые звонки = нет данных.
- МЦП восстановлена из свежего отчёта Auto.ru: `Цена продажи / (% цены к МЦП / 100)`.
- Ниже МЦП считается по формуле: факт продажи < восстановленная МЦП.
- Риск-скоринг нужен для приоритизации ручной проверки, не для юридического вывода о нарушении.
